# 康乃馨 7.0

可在手机横屏游玩的第一人称 3D 花海书咖漫游。场景有四层书廊、沙发夹层和花海舞台。

[在线体验](https://lyn.lipopo.org/) · [版本改动记录](CHANGELOG.md)

刘宇宁的正面人物图和 11 本杂志就绪后可进入。其他人物视角、呆米、剧照和唱片在后台继续加载。

## 玩法

左侧摇杆移动，右侧摇杆转动视角。电脑可用 WASD 或方向键移动，拖动画面转向。电脑按空格跳跃，在空中再按一次可二段跳。

- 靠近心心或书架上的收藏，长按按钮 2 秒。
- 集齐 5 颗心心和 11 本杂志后，到舞台和呆米打招呼。
- 解锁隐藏任务后，可以在书架收集 12 个影视角色。全部完成后还可以探索唱片彩蛋、留下墙上留言并生成可分享的图片。保存留言留影后可进入花海合影，选一张本机照片，选择正面合影或侧身对唱，调整脸部位置并另存一张合影。照片全程在浏览器中处理。
- 右上角可以调画质、播放现场原声或选择本机音频。现场原声由微博提供，按需播放。

## 彩蛋测试

进入花房后，快速点击画面左上角的透明热区十次，可完成前置任务并回到一楼舞台。唱片仍需到一楼背墙长按领取。

## 本地运行

需要 Node.js 和 Python 3。无需安装 npm 依赖。

```sh
npm start
```

打开 [http://localhost:4173](http://localhost:4173)。网页源码和静态资产在 `dist/`，其中包含 Three.js 和 HLS.js。HTTPS 站点支持缓存完成后的离线访问。

主站与备用站从同一服务领取唱片收藏编号，起号为 `No.000001`。[查看已发到的编号](https://lyn.lipopo.org/api/record-number)。两站共用一楼留言墙。玩家选择「发布到留言墙」时会上传留言文字，照片全程在本机处理。本地运行使用 `.local/record-numbers.sqlite3`，与线上序列独立。

主站和备用站的访问数据汇总到[私密统计页](https://lyn.lipopo.org/stats/)，需要管理者密钥。同一浏览器在同一站点的多次访问按一个去重访客计算，同时记录页面打开次数和点击开始收集的次数。统计以北京时间分日。

私密统计页的「全部留言」按唱片编号列出所有已发布留言。

游玩进度、随机点位和最近的落脚位置保存在当前浏览器。刷新后选择「继续漫游」可接着收集。私密统计页的游玩漏斗按页面计数，记录加载完成、加载失败和第一次实际收集。挑战漏斗按浏览器和站点统计心心、杂志、影视角色和唱片的开始、完成及完成率。

遇到首屏加载卡住时，可点「修复并重新加载」或打开[主站修复链接](https://lyn.lipopo.org/?repair=1)。修复会重置花房资源缓存，以普通画质重试，保留本机游玩进度。

混凝土、木纹、布纹和叶脉贴图在浏览器生成。日光和夜色各使用一套预计算的间接光与环境遮蔽，浏览器通过三维光照贴图读取。超清画质还会计算固定建筑的直射投影。

调整窗户、楼板或灯位后，可用 `node scripts/bake-atrium.mjs` 从场景几何重新生成间接光贴图。

## 测试与打包

```sh
npm run check
python3 scripts/package_release.py pack --build 20261113-r68
```

测试覆盖楼层和楼梯可达性、收集交互、人物照片展示和离线缓存。打包脚本根据 `dist/` 生成发布归档和 SHA-256 清单。

## 素材

这是非官方粉丝作品。场景参考现场影像，空间与尺寸作了艺术化处理。人物贴图、杂志封面与影视剧照的相关权利归各权利人所有。

- 呆米的叫声采用 [Tiny Dog Bark](https://freesound.org/people/qubodup/sounds/813120/)（CC0）。
- 收集提示音采用 Kenney 的 [Interface Sounds](https://kenney.nl/assets/interface-sounds)（CC0）。
- 第三方库和字体的许可证随素材存放在 `dist/` 下。
